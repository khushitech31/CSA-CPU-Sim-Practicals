# CSA CPU Simulation Practicals

**Course:** Computer System Architecture  
**Tool:** CPU Sim

## About
This repository contains my Computer System
Architecture lab practicals using CPU Sim.

## Practicals

1. Create a Machine (Basic Computer Architecture)
2. Create the Fetch Routine
3. Addition of Two Numbers
4. Subtraction of Two Numbers
5. Logical Operations
6. Memory-Reference Instructions
7. Register-Reference Instructions
8. Additional Register-Reference Instructions
9. Circular Shift Instructions
10. Sum Until a Negative Number
11. Sum Until Zero

## Purpose
To understand computer architecture and
instruction execution through practical work.
